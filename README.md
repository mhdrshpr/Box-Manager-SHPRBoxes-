# 📦 شپر باکسِز (SHPRBoxes)
### سامانه مینیمال و هوشمند مدیریت محلی کارتن‌ها، انبار و بارکدهای QR

**شپر باکسِز (SHPRBoxes)** یک داشبورد تک‌صفحه‌ای (SPA) زیبا، سبک و آفلاین برای مدیریت اثاث‌کشی، انبار شخصی، کارگاه یا سازماندهی کارتن‌ها و جعبه‌ها است. این پروژه بدون نیاز به هیچ‌گونه فریم‌ورک یا کتابخانه سنگین بیرونی، صرفاً با زبان‌های پایه وب (**Vanilla JS / CSS3 / HTML5**) طراحی شده و اطلاعات را در یک فایل JSON ساده یا در حافظه مرورگر مدیریت می‌کند.

---

## ✨ ویژگی‌های برجسته

### 📦 ۱. کارتن‌های سه‌بعدی و گرافیکی (3D Carton Cards)
- نمایش هر کارتن با ظاهر **۳ بعدی مقوایی جذاب** شامل درپوش، چسب بسته‌بندی، بارکد، استمپ شکستنی (`FRAGILE`) و نشانگر سایز.
- انطباق ابعاد کارتن سه‌بعدی با **۵ سایز استاندارد** (خیلی کوچک `XS` تا خیلی بزرگ `XL`).
- امکان کلیک روی کارت برای ورود سریع به نمای جزئیات کارتن.

### 🏷️ ۲. موتور تولید و چاپ برچسب QR Code اختصاصی
- تولید آنی کد QR برای هر کارتن به همراه **درج شناسه متنی کارتن در زیر QR** جهت خوانایی و شناسایی سریع.
- امکان دانلود تصویر QR Code با کیفیت مناسب.
- قابلیت پرینت برچسب فیزیکی با استاندارد پرینت تمیز و بدون صفحه سفید اضافی (با سیستم Isolated Print Iframe) برای چسباندن روی کارتن‌ها.

### 📷 ۳. اسکنر هوشمند بارکد (دوربین زنده + فایل تصویر)
- **اسکنر با دوربین:** استفاده از وب‌کم لپ‌تاپ یا دوربین موبایل برای اسکن مستقیم کارتن و باز شدن فوری اطلاعات آن.
- **اسکن از فایل:** امکان بارگذاری عکس بارکد یا انتخاب از گالری و دکود سریع با کتابخانه بهینه‌شده `jsQR`.

### 🔍 ۴. جستجوی زنده با هایلایت هوشمند (Live Search & Highlight)
- جستجوی آنی در شناسه، عنوان و اقلام ثبت‌شده درون کارتن‌ها.
- **هایلایت خودکار کلمات پیدا شده** با برچسب زردخوانا (`<mark class="search-highlight">`).
- اولویت‌بندی هوشمند اقلام در کارت کارتن: آیتمی که با عبارت سرچ مطابقت دارد بلافاصله در پیش‌نمایش ۳تایی کارت بالا می‌آید.

### 🎲 ۵. تولید تصادفی شناسه کارتن و اعتبارسنجی زنده
- دکُمه تولید شناسه تصادفی با فرمت استاندارد `BOX-` و ۳ الی ۵ رقم منحصربه‌فرد (مانند `BOX-102` یا `BOX-48215`).
- **بررسی بلادرنگ (Live Validation)** تکراری بودن کد: در صورت وجود کد مشابه در دیتابیس، حاشیه فیلد قرمز شده، متن راهنما به هشدار خطا تبدیل گشته و دکمه ذخیره قفل می‌شود.

### 📱 ۶. طراحی مدرن، شناور و شیشه‌ای (Glassmorphism & Mobile First)
- **نوبار و هدر شناور در موبایل:** هر دو بخش با فاصله از لبه‌ها، گوشه‌های کاملاً گرد (`border-radius: 24px`) و افکت شیشه‌ای مات (`backdrop-filter: blur(18px)`) طراحی شده‌اند.
- **شبکه چیپ‌های مکانی:** در نسخه موبایل دسته‌بندی‌ها به صورت ۲ستونه منظم قرار گرفته و گزینه «همه مکان‌ها» کل سطر بالا را پوشش می‌دهد.
- پشتیبانی کامل از **تم روشن و تاریک (Light / Dark Mode)** با کنتراست ارگونومیک.

### 🔒 ۷. حفاظت داده‌ها و تأیید حذف چندمرحله‌ای
- مودال اختصاصی و ایمن برای عملیات حساس (حذف کارتن یا مکان) با هشدار صریح غیرقابل بازگشت بودن و لزوم فعال‌سازی تیک تأیید.
- مدیریت خطای نبود فایل داده: چنانچه `data.json` موجود نباشد، سامانه با دیتابیس پیش‌فرض بالا آمده و در حافظه محلی کش می‌سازد.
- امکان پشتیبان‌گیری، خروجی گرفتن (`Download JSON`) و بازیابی دیتابیس (`Import JSON`).

## 🚀 نحوه راه‌اندازی و اجرا

این سامانه به هیچ ابزار بیلد، نصب npm یا کانفیگ سرور پیچیده‌ای نیاز ندارد.

### روش ۱: اجرای مستقیم
فایل `index.html` را در هر مرورگری (Chrome, Firefox, Edge, Safari) باز کنید. تمامی امکانات از جمله مدیریت کارتن‌ها، فیلترها و خروجی‌ها فعال خواهند بود.

### روش ۲: اجرای با وب‌سرور محلی (پیشنهادی برای اسکنر دوربین)
مرورگرها به دلایل امنیتی دسترسی به وب‌کم (`getUserMedia`) را روی پروتکل `file://` مسدود می‌کنند. برای استفاده از **اسکن زنده با دوربین**، پروژه را با یک سرور لوکال اجرا کنید:

#### با استفاده از Python:
```bash
# وارد پوشه پروژه شوید
cd "Box Manager"

# اجرای سرور محلی پایتون روی پورت 8000
python -m http.server 8000
```
سپس مرورگر خود را باز کرده و به آدرس زیر بروید:
```text
http://localhost:8000
```

#### با استفاده از افزونه Live Server در VS Code:
کافیست روی فایل `index.html` راست‌کلیک کرده و گزینه **Open with Live Server** را انتخاب کنید.

## 🛠️ تکنولوژی‌های به‌کاررفته

- **زبان‌ها:** HTML5 سمانتیک، CSS3 مدرن (CSS Grid, Flexbox, CSS Variables, 3D CSS Transforms, Media Queries)، جاوااسکریپت ماژولار و بومی (ES6+).
- **فونت و تایپوگرافی:** فونت فارسی «درباره» (Darbareh Web).
- **آیکون‌ها:** Google Material Symbols Rounded (بدون فونت خارجی اضافه و با سازگاری بالا).
- **تولید بارکد:** کتابخانه بهینه و بدون وابستگی `qrcode.min.js`.
- **اسکن بارکد:** کتابخانه پردازش تصویر `jsqr.min.js`.
